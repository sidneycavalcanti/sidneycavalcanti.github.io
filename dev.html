Conferindo os serviços…

Os dados vêm das páginas oficiais de status de cada empresa e atualizam sozinhos a cada minuto.

Clique no nome de um serviço para abrir a página oficial de status dele.

AWS, Azure e Microsoft 365 não deixam o navegador ler o status direto, então um robô no GitHub busca esses três a cada 5 minutos (às vezes atrasa um pouco). Na AWS, só conta como falha grave o que afeta São Paulo, N. Virginia ou serviços globais.

Bancos tradicionais (Itaú, Bradesco, Banco do Brasil, Caixa) não publicam status em tempo real. Por isso aparecem os meios de pagamento que publicam.
